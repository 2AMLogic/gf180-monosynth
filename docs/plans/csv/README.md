# The scorecard lives as CSV, not XLSX

The workbook it came from is deliberately not in the repository: a binary you
cannot read from a console is hostile to the way this project is worked on, and
it cannot be diffed, grepped or reviewed in a pull request.

The three sheets are exported here, and `docs/scorecard/cases.csv` is the
machine-readable source the tooling actually reads. The spreadsheet is a view;
these are the evidence.
