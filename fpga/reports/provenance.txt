## what is in this build
  THE REAL DRUM SECTION. drum_regs + drum_kit (drum_dp + modal_dp) are
  instantiated by rtl-sketch/synth_top.v and are in the file list below.
  There is no drum_section_placeholder in this tree: grep says so, and
  fpga/reports/scope.txt records the check. Every synth_top FPGA figure
  published by this repository before 2026-09-18 was a chip WITHOUT them
  (provenance of that build: commit 3372e789, branch flow/fpga).
  The routed file set equals rtl-sketch/verify_synth_top.py's SRCS; the
  `srccheck` target asserts it and `all` runs it first.

## the clock
  ULX3S: 25 MHz oscillator -> EHXPLLL -> 12.288135593 MHz (+11.03 ppm,
  +0.019 cents; fs = 48000.530 Hz). CLKI_DIV=1 CLKFB_DIV=1 CLKOP_DIV=29
  CLKOS_DIV=59, VCO 725 MHz, PFD 25 MHz. Reproduce with
  fpga/scripts/pll_search.py. The constraint nextpnr met is the one it
  DERIVED from that PLL, not one asserted in the LPF.
  iCE40: no PLL can reach 12.288 MHz from 12 MHz (output range starts at
  16 MHz); that target is constrained at 12.288 MHz and the board
  must carry the oscillator.
